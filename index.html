Task for Spaces

Version 1.3.6 · A tiny macOS menu-bar app

Know what every Space is for.

Give each macOS Space a name. Task shows it across that Space's thumbnail in Mission Control, so you can see what each one holds.

Download on the Mac App Store

The name, up in the menu bar

Turn on Icon as Space Names and the tag carries the first word of the Space you are on rather than its number. The Space you are working in is readable without opening anything.

Names in Mission Control

Every named Space carries a large badge across the middle of its thumbnail, split over two lines when the name is long.

Differentiate with Color

Each named Space takes its own color from across the spectrum. Colors are saved and survive relaunches.

Rename in place

Click the menu-bar tag. The current name arrives selected, so you can type straight over it.

Reordering keeps up

Drag your Spaces into a new order and each name and color travels with its own Space, not with the Desktop number.

Your Desktop, at a glance

The menu-bar tag shows the current Desktop number. Fullscreen and Split View Spaces leave it blank, because macOS gives them no number.

Small and local

One plain text file holds your whole workspace. No account, no analytics, no cloud, no ads. Task stays in the menu bar and out of the Dock.

New in 1.3.6

  • The menu-bar tag can carry the first word of the Space's name in place of its Desktop number.
  • The tag keeps one width whatever the name, so the menu bar does not shift as you move between Spaces.

Configuration file (spaces.txt)

# Task configuration # This file is managed by Task. Manual edits are supported, but Task # normalizes formatting and discards custom comments and unknown keys when saving. # Active-badge visibility after Desktop changes (0.0 disables it; max 5.0) splashDuration = 1.5 # Give each named Desktop a stable colour differentiateWithColor = true # Show the first word of the Desktop's name in the menu bar, # in place of its number iconAsSpaceNames = false # Desktop names 1 = Website refresh 2 = PROJ-4127 3 = Customer research 4 = Invoices # Per-Desktop badge colours 1.color = #E8756A 2.color = #2F80ED

Space names, their colors and the splash duration live in this one local file. Open it from Task’s menu and edit it by hand, or let Task write it as you rename Spaces. Task follows the system’s light or dark appearance.

Before you start: Task needs two Mission Control settings turned off in System Settings → Desktop & Dock — Displays have separate Spaces and Automatically rearrange Spaces based on most recent use. There is more in Support.
