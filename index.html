Task for Spaces

Version 1.1.0 · A tiny macOS menu-bar app

Know which Desktop is which.

macOS gives you Desktop 1, Desktop 2, Desktop 3. Task gives them names and writes each name across its thumbnail in Mission Control, so the overview tells you where everything is. The menu-bar tag shows the Desktop you are on right now.

Download on the Mac App Store

Task needs two Mission Control settings turned off in System Settings → Desktop & Dock: Displays have separate Spaces and Automatically rearrange Spaces based on most recent use.

Names in Mission Control

Every named Desktop carries a large badge across the middle of its thumbnail, split over two lines when the name is long.

Differentiate with Color

Each named Desktop takes its own colour from across the spectrum. Colours are saved and survive relaunches.

Rename from the menu bar

Click the numbered tag. The current name arrives selected, so you can type straight over it.

Reordering keeps up

Drag Desktops into a new order and each name and colour travels with its own Desktop, not with the number.

Your Desktop, at a glance

The menu-bar tag holds the current Desktop number. Fullscreen and Split View Spaces leave it blank, because macOS gives them no number.

Small and local

No account, no analytics, no cloud, no ads. Task stays in the menu bar and out of the Dock.

New in 1.1.0

  • Named Desktops keep their badge in Mission Control, rather than showing it only for a moment as you switch.
  • Differentiate with Color gives every named Desktop its own colour, saved alongside its name.
  • Renaming is quicker: the field in the menu opens with the current name selected and saves when you finish.

Configuration file (spaces.txt)

# Task configuration # This file is managed by Task. Manual edits are supported, but Task # normalizes formatting and discards custom comments and unknown keys when saving. # Active-badge visibility after Desktop changes (0.0 disables it; max 5.0) splashDuration = 1.5 # Give each named Desktop a stable colour differentiateWithColor = true # Desktop names 1 = Website refresh 2 = PROJ-4127 3 = Customer research 4 = Invoices # Per-Desktop badge colours 1.color = #E8756A 2.color = #2F80ED

Names, colours and settings live in this one local file. Open it from Task's menu and edit it by hand, or let Task write it as you rename Desktops. Task follows the system’s light or dark appearance.
