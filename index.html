Task for Spaces

Version 1.0.6 · A tiny macOS menu-bar app

Know what every Space is for.

Task gives each macOS Space a meaningful name, then shows it when you switch desktops, open Mission Control, or click its menu-bar icon. The menu-bar icon shows your current numbered Desktop at a glance.

Your Desktop, at a glance

The menu-bar tag shows the current Desktop number.

Rename in place

Right-click Task to edit the current Desktop name.

Set the splash duration

Choose how long the Space-name splash stays visible, from 0.1 to 5.0 seconds.

Configuration file (spaces.txt)

splash_duration = 1.5 1 = Focus work 2 = Email and messages 3 = Research and reference 4 = Planning and admin

Space names and splash duration live in this local file. Task follows the system’s light or dark appearance.
