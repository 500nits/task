New in 1.4.0

  • Pick one of five splash sizes, from huge to mini.
  • Place the splash anywhere on a three-by-three grid. Task keeps it clear of the Dock and Mission Control’s Spaces bar.
  • Show or hide the splash over the Desktop when Mission Control is open.
  • Give each Space its own menu-bar tag with N.tag—handy when two Space names start with the same word.
  • Names in the Spaces bar stay full size, no matter which splash size or position you choose.

Configuration file (spaces.txt)

# Task configuration # Task manages this file. You can edit it by hand, but when Task # saves it, it reformats the file and removes custom comments and # unknown settings. # How long the splash stays on screen after a Space change, in seconds. # 0.0 turns it off, 5.0 is the longest. splashDuration = 1.5 # Give each named Desktop a stable color differentiateWithColor = true # Show the first word of the Desktop's name in the menu bar # instead of its number iconAsSpaceNames = false # Desktop names 1 = Website refresh 2 = PROJ-4127 3 = Customer research 4 = Invoices # Per-Desktop colors 1.color = #E8756A 2.color = #2F80ED

This local file stores your Space names, colors, and splash duration. Open it from Task’s menu to edit it yourself, or let Task update it as you rename Spaces. Task follows your Mac’s light or dark appearance.

Before you start, open System Settings → Desktop & Dock and turn off Displays have separate Spaces and Automatically rearrange Spaces based on most recent use. See Support for setup details.
