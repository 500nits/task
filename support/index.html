Task for Spaces

Support

Task is a small macOS menu-bar app that lets you attach a meaningful description to each numbered Space, so you can see what every desktop is for at the moments when context matters.

Getting started

For Task to keep its numbers aligned with Mission Control, open System Settings → Desktop & Dock → Mission Control and turn off:

  • Displays have separate Spaces
  • Automatically rearrange Spaces based on most recent use

Task stays in the menu bar. It does not appear in the Dock.

Name your Spaces

Right-click the Task menu-bar icon and choose Configuration…. Task opens a local plain-text file in your default text editor. Add one numbered description per line:

1 = DoodleTag · replay investigation
2 = Botify · provider work
3 = Website · indexing
4 = Admin

The file is stored locally at:

~/Library/Containers/com.500nits.Task/Data/Library/Application Support/Task/spaces.txt

When Task appears

Your current Space name appears briefly when you:

  • move to another Space;
  • open Mission Control;
  • wake or unlock your Mac; or
  • left-click the Task menu-bar icon.

If you use more than one display, Task shows the name on every connected display. Fullscreen Spaces are shown as FS · Fullscreen Space.

Menu-bar controls

Right-click the Task icon to open its menu. From there you can edit the configuration, enable or disable Start at Login, read the About panel, or quit Task. Start at Login is always opt-in.

Troubleshooting

The wrong name appears

Confirm that both Mission Control settings listed above are off, then check that the number in spaces.txt matches the Space’s position in Mission Control.

No name appears after editing

Save the configuration file as plain text. Keep one mapping per line in the form number = description, then switch Spaces or left-click the menu-bar icon.

Task is not visible

Look for its tag-shaped icon in the macOS menu bar. If the menu bar is crowded, macOS or a menu-bar manager may have hidden it.

Contact support

For help, email apps@500nits.com. Please include your macOS version and a short description of what happened.
