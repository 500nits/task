Task for Spaces

Support

Version 1.3.6. Task is a small macOS menu-bar app that gives each macOS Space a meaningful name, keeps that name visible in the Mission Control overview, and shows your current numbered Desktop in the menu bar.

Getting started

For Task to keep its numbers aligned with Mission Control, open System Settings → Desktop & Dock → Mission Control and turn off:

  • Displays have separate Spaces
  • Automatically rearrange Spaces based on most recent use

Task stays in the menu bar. It does not appear in the Dock.

The tag-shaped menu-bar icon contains the current numbered Desktop. Fullscreen and Split View Spaces leave the tag unnumbered, and carry no name, because macOS does not assign them a Desktop number.

Name your Spaces

Click the Task menu-bar icon. The text field at the top of the menu holds the current Space’s name, already selected, so you can type straight over it. The name is saved when you press Return, click elsewhere, or close the menu.

For bulk edits, choose Configuration…. Task opens the local plain-text file in your default text editor. Add one numbered Space name per line:

# Task configuration
# This file is managed by Task. Manual edits are supported, but Task
# normalizes formatting and discards custom comments and unknown keys when saving.

# The splash is the large card Task draws in the middle of the
# screen: for a moment when you move to a Space, and while Mission
# Control is open. The name Mission Control shows in its Spaces bar
# is a separate thing, and none of the four settings below touch it.

# How long the splash stays after a Space change, in seconds.
# 0.0 turns it off, 5.0 is the longest.
splashDuration = 1.5

# Draw the splash over the Desktop while Mission Control is open.
# The Spaces bar keeps its names either way.
splashInMissionControl = true

# How large the splash is drawn.
# One of: huge, big, normal, small, mini. huge is the default.
splashSize = huge

# Where on the screen the splash sits, as a 3x3 grid read like a page:
#   1 2 3   top left, top centre, top right
#   4 5 6
#   7 8 9   bottom left, bottom centre, bottom right
splashPosition = 5

# Give each named Desktop a stable colour
differentiateWithColor = true

# Show the first word of the Desktop's name in the menu bar,
# in place of its number
iconAsSpaceNames = false

# Desktop names
1 = Website refresh
2 = PROJ-4127
3 = Customer research
4 = Invoices

# Per-Desktop colours, and what the menu-bar icon shows
# for that Desktop when "Icon as Space Names" is on. Without a
# tag the icon shows the first word of the name, which collides
# when two Desktops start with the same word.
1.color = #E8756A
1.tag = SITE
2.color = #2F80ED

The file is stored locally at:

~/Library/Containers/com.500nits.Task/Data/Library/Application Support/Task/spaces.txt

Task does not overwrite the file when it launches or when you switch Spaces. It writes when you rename a Space, release the splash-duration slider, toggle Differentiate with Color, refresh the workspaces, or complete a verified numbered-Desktop reorder in Mission Control.

spaces.txt is an app-owned canonical file. When Task writes it, duplicate entries collapse to their last value, custom comments, unknown keys and custom formatting are removed, and entries beyond the number of Spaces you actually have are dropped. Every live Space always ends up with a concrete name; a missing or cleared entry is written back as Task N.

If you drag your Spaces into a new order in Mission Control, Task uses their stable identities to move each name — and its color — to its new Desktop number automatically.

Names in Mission Control

Each named Space carries its name across the middle of its thumbnail in Mission Control's Spaces bar. The name uses the full available screen width at a fixed size; a name too long for one line splits over two, and a name that still does not fit displays overflown.

The splash appears when you open Mission Control, and briefly after you move to another Space. The rest of the time it stays invisible and your screen is unobstructed, including in Application Windows.

Differentiate with Color

Click the Task menu-bar icon and choose Differentiate with Color. Each named Space is given its own color, distributed across the full spectrum and randomly rotated, so Spaces next to each other stay easy to tell apart.

Colors are written into spaces.txt as N.color entries and survive ordinary relaunches. Switching the option off and back on generates a fresh set. To choose your own, edit the file and give a three- or six-digit HTML hex color; Task stores the canonical six-digit #RRGGBB form.

Splash size and position

The splash is the large card Task draws in the middle of the screen: for a moment when you move to a Space, and while Mission Control is open. Three settings in spaces.txt shape it. They have no menu item because they are set once and then left alone: edit the file from Configuration… and open Mission Control to see the change.

None of them touch the name in Mission Control's Spaces bar. That name stays full size and centred whatever they say, because the thumbnail it sits on is only a couple of hundred pixels wide and reading the name in it is the whole point.

splashInMissionControl

true or false. Draws or hides the splash over the Desktop while Mission Control is open. The Spaces bar keeps its names either way.

splashSize

One of huge, big, normal, small or mini. The size applies to the whole splash at once, so it keeps its shape and only its scale changes, and it applies to the splash shown on a Space change as well as the one in Mission Control. huge is the default. This is the one splash setting that is also in the menu, on a Splash size slider beside the duration one. It has five stops, smallest on the left, and the label above it names the one you are on. Edit the file by hand instead and the slider shows that the next time you open the menu.

splashPosition

A number from 1 to 9, placing the splash on a three-by-three grid read like a page:

1 2 3   top left, top centre, top right
4 5 6   left, centre, right
7 8 9   bottom left, bottom centre, bottom right

5, the centre, is the default. The outer rows are held off the edges: the top row clears Mission Control's Spaces bar and the bottom row clears the Dock, so a splash in a corner stays readable with either of them on screen. A name Task does not recognise, or a number outside 1 to 9, is ignored and the default is kept, so a typo never leaves the splash somewhere unexpected.

Icon as Space Names

Click the Task menu-bar icon and choose Icon as Space Names. The tag then carries the first word of the current Space’s name in place of its Desktop number.

The tag keeps one width whatever the name is, so the rest of the menu bar stays where it is as you move between Spaces. A word too long for that width is cut, with an ellipsis to show where. Fullscreen and Split View Spaces have neither a name nor a Desktop number, so the tag stays blank on those either way.

The first word is a default, and it collides: Client Alpha and Client Beta both read Client. Give a Space its own tag by adding N.tag to spaces.txt, next to its colour:

1 = Client Alpha
2 = Client Beta
1.tag = ALPHA
2.tag = BETA

A tag is used exactly as written, spaces included, and is fitted to the tag the same way a name is. Remove the line, or leave it empty, and that Space goes back to its first word. A tag follows its Space when Spaces are reordered, and goes when the Space does.

The setting is written to spaces.txt as iconAsSpaceNames.

Set the splash duration

Click the Task icon and use the Splash duration slider. It controls how long the splash stays visible after you move to a Space. Choose any value from 0.0 to 5.0 seconds; the default is 1.5 seconds, and 0.0 turns off the splash on a Space change while leaving the one in Mission Control in place.

The value is saved when you release the slider, as splashDuration in spaces.txt. If that setting is missing or invalid, Task uses the 1.5-second default without rewriting the file.

When Task appears

A Space’s name is shown:

  • across its thumbnail whenever Mission Control is open;
  • on screen for the splash duration when you move to that Space.

If you use more than one display, Task shows the name on every connected display.

Menu-bar controls

Task’s tag carries the current numbered Desktop, or that Space’s name when Icon as Space Names is on. Click the icon for:

  • the editable name of the current Space;
  • Differentiate with Color;
  • Icon as Space Names;
  • the Splash duration slider;
  • Refresh Workspaces, which rereads spaces.txt, reconciles the names against the Spaces that are actually there, and shows the current Desktop’s splash so you can see it worked;
  • Configuration…, which opens spaces.txt in your default text editor;
  • Start at Login, always opt-in — Task never enables it for you;
  • About Task and Quit Task.

Troubleshooting

The wrong name appears

Confirm that both Mission Control settings listed above are off, then check that the number in spaces.txt matches the Space’s position in Mission Control. Refresh Workspaces reconciles the two.

No name appears after editing

Edits in the menu field save when you press Return, click elsewhere, or close the menu. If you edit the full configuration instead, save it as plain text and keep one mapping per line in the form number = name. Then switch Spaces or choose Refresh Workspaces.

No name appears in Mission Control

Only a named Space with a Desktop number is named in the Spaces bar. Fullscreen and Split View Spaces never are. If a numbered Space is missing its name, choose Refresh Workspaces.

Task is not visible

Look for its numbered tag-shaped icon in the macOS menu bar. If the menu bar is crowded, macOS or a menu-bar manager may have hidden it.
